# Flutter (Mobile App Dev)

A comprehensive learning repository for **Mobile Application Development using Flutter and Dart**. This repository contains practical work, assignments, coding exercises, and projects developed throughout the semester, covering Flutter fundamentals, UI design, state management, backend integration, and mobile app deployment.

## 📚 Course Overview

This course focuses on developing cross-platform mobile applications using **Flutter and Dart**, from basic programming concepts to building and deploying complete mobile applications.

## 🗂️ Topics Covered

### 1. Environment Setup & Dart Fundamentals
- Introduction to mobile application development and Flutter.
- Flutter SDK, Android Studio, VS Code, and emulator setup.
- Dart programming fundamentals, OOP, and asynchronous programming.

### 2. Flutter Fundamentals & UI Development
- Flutter project structure and core widgets.
- Layouts, styling, themes, forms, and responsive UI.
- Navigation, routes, dialogs, and multi-screen applications.

### 3. Packages, Storage & State Management
- Flutter packages and dependency management.
- Local storage using SharedPreferences and secure storage concepts.
- State management using Provider and ChangeNotifier.

### 4. APIs & Backend Integration
- REST APIs, HTTP requests, JSON, and error handling.
- Firebase and Supabase fundamentals.
- Authentication, cloud databases, CRUD operations, and storage.

### 5. Advanced Features & Application Development
- Notifications, media handling, charts, and device integrations.
- Application architecture, debugging, testing, and Git/GitHub.
- Payment integration concepts and third-party SDKs.

### 6. Build, Deployment & Semester Project
- Debug and release builds, APK/AAB generation, and signing concepts.
- Google Play Console and iOS deployment overview.
- Semester project development, demonstration, presentation, and viva.

## 🛠️ Technologies & Tools

- **Flutter** – Cross-platform mobile application framework
- **Dart** – Programming language
- **Android Studio / VS Code** – Development environments
- **Firebase / Supabase** – Backend and cloud services
- **Git & GitHub** – Version control and project management
- **REST APIs & JSON** – Data communication and integration

## 📁 Repository Contents

This repository includes weekly practicals, Dart programs, Flutter UI exercises, assignments, API integrations, and semester project development.

## 🎯 Learning Objectives

- Develop cross-platform mobile applications using Flutter.
- Build interactive and responsive user interfaces.
- Implement state management and backend integration.
- Apply clean coding, debugging, and testing practices.
- Understand the process of building and deploying mobile applications.
